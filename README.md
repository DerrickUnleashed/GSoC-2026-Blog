# GSoC 2026 - Derrick Richard

Website for my Google Summer of Code 2026 contribution journey with **mlverse**, extending TorchVision support in R for computer vision tasks.

## Live Site

[derricksamuel.github.io/GsocWebsite](https://derricksamuel.github.io/GsocWebsite)

## What I Worked On

- **Item transforms** for detection & segmentation data augmentation pipelines (hflip, vflip, crop, pad, perspective, random crop, random erasing, etc.)
- **RF-DETR** object detection model implementation using preexisting LW-DETR utilities
- **Rotated bounding box** coordinate transforms and IoU utilities
- **SAHI** (Slicing Aided Hyper Inference) for small object detection
- **roi_align_rotated** CUDA operation in torchvisionlib
- CI improvements, documentation fixes, dataset reliability fixes
